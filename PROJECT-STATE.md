# ai-ch — состояние проекта

## Назначение

Приватное ИИ-пространство для чатов с ветками, работы с файлами, поиска, памяти и настроек модели.

## Render

- Развёртывание через `render.yaml` и `Dockerfile`.
- Сервис слушает `PORT`; health check — `/api/health`.
- Обязательная переменная: `QWEN_API_KEY`; endpoint и модель задаются через `QWEN_BASE_URL` и `QWEN_MODEL`.
- По умолчанию один AI worker. Исполнитель кода и отдельный sandbox-сервис не используются.
- На Render Free SQLite и загрузки хранятся во временной файловой системе; они не гарантированно переживают перезапуски.

## Удалено

- Код-агент и исполнение кода на сервере.
- Консилиум моделей.
- Стенка постов, лайки, комментарии и просмотры.
- Подсказки/плитки главного экрана и статистические панели интерфейса.

## Оставлено

- Приватные чаты, ветки, повтор/продолжение ответа.
- Файлы, память и веб-поиск.
- Выбор набора модели, административные настройки и backend API статистики.
- Ссылки только для чтения на отдельные чаты.
- Дизайн, CSS и файлы шрифтов.
