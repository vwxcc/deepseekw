## 2. Как разворачивать

Код и способ развёртывания зависят от целевой среды. Перед публикацией проверь ветку, diff и статус тестов. Для контейнерного развёртывания:

```bash
cd "$PROJECT_DIR"

# Скопируй только проверенные файлы в настроенный контейнер.
docker cp <local-file> <app-container>:<container-file>
docker restart <app-container>
```

**Не коммить реальные пути хоста, адреса удалённого терминала, команды входа или токены.** Секреты читаются из переменных среды/секретов хостинга и не должны выводиться в логи.

Фронтенд обычно не требует перезапуска отдельного процесса, но после развёртывания нужно проверить актуальность кэша в браузере.

**Коммит и публикация** выполняются только после проверки изменений и при наличии доступа к нужной среде. Токены не должны присутствовать в командах или выводе терминала.

## 3. Secrets and access details

**Do not publish credentials, test passwords, administrator email addresses, terminal URLs, private service hostnames, or machine-specific paths in this file.** Production secrets belong only in the hosting provider's secret environment settings. Keep `.env` out of Git and ensure tracked files contain no real credentials.

If credentials were ever committed or published, deleting them from the latest version is not enough: rotate the affected credentials, inspect the Git history, and rewrite history if required. Never assume a test account is safe to leave enabled on production.

## 5. Что уже готово

### Интерфейс
- Тёплая тема в стиле Claude, тёмная по `prefers-color-scheme`
- Шрифты: **Yandex Sans** (интерфейс) + **Lora** (литературный: приветствие, заголовок чата, поле ввода)
- Боковая панель: внизу одной строкой `[👤 имя] … [🌐] [📊]` — иконки прижаты вправо
- **Плитки главной страницы** с цветными логотипами (сочинение, Word, презентация, Excel, код, схема, график, поиск…)
- **Плавное заполнение полоски лимита прямо во время стриминга**
- Кнопки **память / лимиты / модель** одной высоты (34 px)

### Лимиты и тарифы
- **Деньги, а не токены:** бюджет в долларах на скользящее окно (по умолчанию 5 часов)
- Считается **ВСЁ**: ответ, заголовок чата, подсказки, роутинг, поисковые запросы, **сжатие истории**
- Пользователь видит **только процент и полоску**, в подсказке — `$потрачено из $бюджета`
- **Админка:** горизонтальная таблица `Лимит | Free | Pro`, все ключи на виду
- **Цены у каждой модели:** вход / выход / кэш, $ за 1M токенов + живой калькулятор
- **Кнопка сброса лимитов** для Free, Pro и обоих сразу
- Редактирование кластеров: модель, URL, ключ, temperature, макс. ответ, макс. контекст, цены

### Генерация документов (`designs.docgen`)
- **PPTX** — титульный слайд, разделители, буллиты, две колонки, KPI-карточки, графики, таблицы, цитаты
- **DOCX** — титульная страница, заголовки, врезки, таблицы с зеброй, номера страниц
- **XLSX** — стилизованная шапка, зебра, автоширина, итоги с формулами
- **PDF** — многостраничный (matplotlib, без LibreOffice)
- **8 типов графиков** + **PNG-превью каждого слайда**
- 57 стилей оформления, шрифты Inter / Lora / PT Serif / Montserrat / Playfair / Manrope
- Образцы: `/assets/samples/` на сервере

### Агент
- Кластеры моделей с fallback-цепочками, авто-роутинг со **сжатием запроса** в краткую суть
- **Авто-повтор** запроса при ошибке той же моделью
- Скиллы: документы, рисунки (SVG), запуск кода, стили, память, уточняющие вопросы
- **Уточняющий вопрос** `[[ask: …]]` → карточка с полем ввода в чате
- Память: факты и предпочтения, чистка мусора на старте

## 7. Грабли (чтобы не повторять)

1. **`docker build` на ZimaOS сломан** — образы собираются через `docker commit` работающего контейнера.
2. **Нельзя вырезать код по якорям «от … до …»** — так я однажды удалил 440 строк (`restore_menu.py`). Только замена по точному тексту или границам функции.
3. **Проверяй, что функция существует, а не только вызов.** Однажды вызов `openUsageModal` остался, а сама функция пропала — кнопка молча не работала.
4. **Версия ассетов** — раньше `?v=26` не менялся, и браузер показывал старый код. Теперь версия берётся из mtime файлов.
5. **`push.py` должен содержать префикс контейнера** в `docker cp`, иначе файлы молча не доезжают.
6. **Новые роутеры нужно добавлять в `push.py`** — иначе правка не уедет на сервер.
7. **PowerShell ломает `$(...)` и кавычки** в here-строках — сложные патчи писать в файл и запускать `python3 файл.py`.
8. **Сеть в песочнице отсутствует** — всё нужное ставить в образ или монтировать через `/srv`.
