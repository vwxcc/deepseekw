# ai-ch

Приватное ИИ-пространство: личные чаты с ветками, загрузка и разбор файлов, веб-поиск, память и настройки модели.

## Возможности

- Приватные чаты, поиск по истории, переименование и ветвление ответов.
- Потоковая генерация, остановка, повтор и продолжение ответа.
- Загрузка файлов и изображений; вложения передаются модели.
- Веб-поиск с запасным прямым поиском, если SearXNG не настроен.
- Память о фактах и предпочтениях.
- SVG-схемы, HTML-превью и экспорт ответа.
- Настройки набора модели и администрирование.
- Отдельная ссылка только для чтения на конкретный чат.
- Светлая/тёмная тема и адаптивный интерфейс.

## Развёртывание на Render

1. На Render выберите **New → Blueprint** и подключите этот репозиторий. Конфигурация находится в `render.yaml`. Также можно создать Web Service с Dockerfile.
2. В переменных окружения задайте `QWEN_API_KEY` — он обязателен. При необходимости настройте `QWEN_BASE_URL` и `QWEN_MODEL`.
3. После развёртывания проверьте `https://ВАШ-СЕРВИС.onrender.com/api/health`.

Приложение слушает порт из переменной `PORT`, предоставляемой Render. Для небольшого сервиса установлен один AI worker; отдельная песочница или второй контейнер не требуется.

## Важно о Render Free

Файловая система бесплатного сервиса эфемерная. SQLite-база и загруженные файлы в `/tmp/data` и `/tmp/uploads` могут исчезнуть при перезапуске или новом развёртывании. Для долговечного хранения нужна внешняя база/файловое хранилище либо тариф с поддержкой постоянного диска; после этого настройте `DATA_DIR` и `UPLOAD_DIR`.

Бесплатный Web Service может засыпать после периода без запросов, поэтому первый запрос после простоя может выполняться дольше.

## Локальный запуск

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Скопируйте `.env.example` в `.env` и укажите `QWEN_API_KEY`.

## Стек

- FastAPI, SQLAlchemy async, SQLite, Pydantic, httpx.
- Ванильный JavaScript без этапа сборки фронтенда.
- Dockerfile и Render Blueprint.

Health check: `/api/health`.
