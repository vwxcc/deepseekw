# ChatStudio

Приватное рабочее пространство с ИИ: чаты с деревом веток, агент с исполнением кода,
память о пользователе, поиск в интернете, стенка постов и консилиум моделей.

Работает как самостоятельное приложение на своём сервере (ZimaOS / Docker).

---

## Возможности

**Чаты**
- Дерево веток: любой ответ можно перегенерировать, продолжить или ответвить заново
  (навигатор `‹ 2/3 ›` под сообщением).
- Стриминг мыслей и ответа, окно размышлений свёрнуто в несколько живых строк.
- Оценка ответов, копирование, «Сохранить как» (TXT / MD / DOCX / PDF / SVG),
  удаление ответа вместе с поддеревом.

**Агент**
- Модель выполняет Python-код в **отдельном изолированном контейнере** и отдаёт файлы
  прямо в чат: docx, xlsx, pptx (презентации), pdf, png, csv, svg.
- Цикл «сделать → проверить → поправить → показать», до нескольких шагов на сообщение.
- Каждый подшаг — отдельная плашка в чате с кодом, stdout/stderr и файлами.
- Защита от гигантских задач: модель предлагает план и спрашивает подтверждение.

**Код-агент**
- Отдельный режим с **постоянной папкой проекта**, которая живёт между сообщениями.
- Панель проекта: дерево файлов и консоль логов выполнения.
- GitHub: логин + токен, `init` / `commit` / `push` / `commit + push`.

**Консилиум моделей**
- Несколько ролей (Прагматик, Аналитик, Критик, Творец) отвечают параллельно
  **в одном чате**, рядом лежит объединённый ответ.

**Auto (Routing)**
- Кластер-маршрутизатор: сначала выбирает подходящую модель, потом отправляет запрос.
  Выбор виден пользователю.

**Знание и память**
- Модель знает, что она ChatStudio AI, и что умеет.
- Память делится на **факты** и **предпочтения**; предпочтения уходят в каждый запрос.
- Автообрезка истории под окно модели.

**Ещё**
- Поиск в интернете (SearXNG) — всегда включён, источники отдельной кнопкой.
- Скилл рисования: SVG-схемы, чертежи с размерными линиями, дуги, стрелки.
- Стенка постов: публикация чата, лайки/дизлайки, комментарии, просмотры, превью.
- Публичные ссылки на чат с возможностью «продолжить у себя».
- Модели и статус: статистика по всем моделям (доля, токены, оценки).
- Загрузка сервера: CPU / RAM / диск рядом с заголовком.
- Тарифы Free / Pro с настраиваемыми лимитами (файлы, хранилище, посты, код-агенты, шаги).
- 30 SVG-аватарок, случайная при регистрации.
- Тёмная тема, адаптивная вёрстка, формулы KaTeX.

## Стек

- **Backend:** FastAPI, SQLAlchemy 2 (async) + aiosqlite, Pydantic v2, httpx, Pillow.
- **Frontend:** ванильный JS + SVG-спрайт, без сборки.
- **Песочница:** отдельный контейнер, внутренняя сеть без интернета,
  read-only rootfs, пользователь `nobody`, лимиты CPU/RAM/PID.
- **Общение с моделью:** OpenAI-совместимый API (vLLM), SSE-стриминг.

## Структура

```
app/
  ai/          провайдер, роутер очереди, промпты
  routers/     auth, chats, messages, files, memory, models,

  main.py      точка входа
frontend/      index.html, css/app.css, js/app.js

```

## Запуск

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Переменные окружения (`.env`): ключи провайдера (`QWEN_*`), `SESSION_SECRET`,
`SEARXNG_URL`, `SANDBOX_URL`, лимиты тарифов.

### Изолированная песочница

```bash
docker network create --internal cs-sandbox
docker run -d --name chatstudio-sandbox \
  --network cs-sandbox --read-only --tmpfs /tmp:rw,size=256m,mode=1777 \
  --user 65534:65534 --memory 1200m --cpus 1.5 --pids-limit 256 \
  --cap-drop ALL --security-opt no-new-privileges \
  -v <data>/sandbox:/work -v <repo>/sandbox:/srv:ro \
  python:3.12-slim python3 /srv/server.py
```

Приложение обращается к ней по HTTP внутри внутренней сети и читает готовые файлы
из общей папки. Интернета у песочницы нет.
