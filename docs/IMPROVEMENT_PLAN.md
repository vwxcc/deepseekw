# AI CH — план улучшений и функциональных пробелов относительно Open WebUI

> Источник: список требований, переданный пользователем в октябре 2026 года. Это план и контрольный список, а не утверждение, что все пункты уже повторно проверены сравнительным аудитом. Непомеченные пункты считаются кандидатами на реализацию, а не готовыми функциями.

## Приоритеты верхнего уровня

1. **Полноценный RAG и Knowledge Bases** — главный функциональный разрыв.
2. **Агентная система и расширяемость** — MCP, Skills, Tools/Functions, внешние серверы инструментов и безопасный терминал.
3. **Realtime voice и многопользовательские каналы** — голосовые разговоры в реальном времени, совместные обсуждения и права доступа.
4. Затем — расширение управления моделями, организация рабочих пространств, артефакты, автоматизации, безопасность и инфраструктура.

При выборе реализации сначала проверить требования к безопасности, приватности и обратной совместимости. Не заменять уже работающий сценарий большим новым блоком без постепенного внедрения и регрессионных проверок.

## 1. RAG и работа с документами — крупнейший разрыв

- [ ] Полноценные Knowledge Bases — коллекции документов.
- [ ] Поддержка нескольких векторных хранилищ: Chroma, PGVector, Qdrant, Milvus, Elasticsearch и другие.
- [ ] Гибридный поиск: BM25 + векторный поиск + reranking.
- [ ] Несколько движков извлечения текста: Tika, Docling, OCR и другие.
- [ ] Agentic retrieval — модель сама ищет документы, читает подходящие фрагменты и уточняет поиск.
- [ ] Full-context mode — передача документа целиком без чанкинга там, где это уместно и безопасно.
- [ ] Файловый браузер с предварительным просмотром Markdown, PDF, изображений, Jupyter и других форматов.
- [ ] Версионирование документов и управление версиями.

## 2. Агенты, инструменты и расширяемость

- [ ] Native MCP (Model Context Protocol).
- [ ] Переиспользуемые Skills: инструкции, файлы и необходимые ресурсы.
- [ ] Расширяемая система Tools / Functions / Actions / Filters / Pipes с безопасным запуском пользовательского кода.
- [ ] Подключение OpenAPI tool servers.
- [ ] Open Terminal: терминал, файловая система и Jupyter в изолированной среде.
- [ ] Tool Search для больших наборов инструментов.
- [ ] Версионирование Skills, Tools и Prompts.
- [ ] Community marketplace для импорта готовых инструментов и пресетов.

## 3. Голос и мультимодальность

- [ ] Realtime voice calls, а не только TTS/STT.
- [ ] 3D-аватары VRM с анимацией речи, жестами и состояниями idle/listening/speaking.
- [ ] Голосовые звонки с переключением между Standard и Realtime.
- [ ] Генерация и редактирование изображений через различные доступные провайдеры, включая GPT-Image, ComfyUI и Gemini, в зависимости от интеграций и API.
- [ ] Видеозвонки и hands-free режим.

## 4. Multi-user и командная работа

- [ ] Полноценные каналы (channels), где могут отвечать несколько участников.
- [ ] Совместные чаты с live replies вместо простого клонирования.
- [ ] Live collaborators — отображение пользователей, находящихся в чате.
- [ ] Вложенные группы и модели по умолчанию для групп.
- [ ] Сквозное шифрование чатов (E2EE) с ясной моделью управления ключами и восстановления.
- [ ] Расширенный RBAC, LDAP, SCIM 2.0, MFA и SSO.
- [ ] Apps в каналах, позволяющие внешним приложениям участвовать в разговоре.

## 5. Модели и управление ими

- [ ] Сравнение моделей side-by-side в одном чате.
- [ ] Расширенный Model Editor: баннер, capabilities и история версий.
- [ ] Динамические переменные вроде `{{USER_NAME}}` и `{{CURRENT_DATE}}`.
- [ ] Model presets, связывающие инструменты, knowledge base и system prompt.
- [ ] Настройка thinking / effort непосредственно в чате.
- [ ] Глобальные настройки по умолчанию и доступ к моделям на уровне пользователя или группы.

## 6. UI/UX и организация

- [ ] Очередь сообщений: возможность подготовить следующее сообщение во время генерации.
- [ ] Папки, теги, закрепления и расширенная организация чатов.
- [ ] Rich editor с AI Enhance.
- [ ] Отдельные Notes с доступом агентов при наличии прав.
- [ ] Compare revision view для сравнения изменений.
- [ ] Панель аналитики.
- [ ] Automations и запланированные запросы.

## 7. Техническая зрелость и инфраструктура

- [ ] Усиленная и регулярно проверяемая система прав и безопасности.
- [ ] Горизонтальное масштабирование и оптимизации через Redis при необходимости.
- [ ] Экосистема плагинов и интеграций для сообщества.
- [ ] Desktop-приложение и дальнейшая полировка мобильного опыта.
- [ ] Готовые Helm-чарты, Kubernetes и корпоративные возможности.

## 8. Дополнительные функции

- [ ] Artifacts — полноценный рендер кода, документов и визуализаций.
- [ ] Task management — структурированные списки задач, с которыми работает модель.
- [ ] Quiz, flashcards и spaced repetition через встроенные функции или плагины.
- [ ] Полноценный in-browser code interpreter с несколькими языками.
- [ ] Более продвинутый sandbox и изоляция выполнения.
- [ ] Системное версионирование моделей, промптов, Skills и Tools.

## Текущая база AI CH — согласно предоставленному списку

- Model Sets, fallback-маршрутизация и экспериментальная параллельная быстрая модель.
- Deep Research agents.
- Учёт токенов и расходов.
- Тарифы Free / Pro.
- Более лёгкий стек: vanilla JavaScript и SQLite.
- Минималистичный интерфейс в стиле Claude.

Эти возможности следует сохранять и проверять регрессиями при реализации новых функций.

## Принципы реализации

- Внедрять крупные блоки поэтапно, с тестами и возможностью отката.
- Для RAG заранее определить формат индексов, обновление и удаление документов, права доступа и изоляцию данных пользователей.
- Выполнять MCP, произвольные инструменты и терминал только через ограниченную среду исполнения с явными правами и аудитом.
- Голосовые и совместные функции проектировать с учётом разрешений браузера, приватности и контроля доступа.
- Не считать пункт завершённым, пока не пройдены проверки кода и реальные сценарии использования.
